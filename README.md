## 🚀 Featured Projects

### 🌟 Pakistan Sign Language (PSL) Translator App
> **Real-time Sign Language Recognition Platform**  
> An impactful assistive technology mobile application. It captures real-time video input of sign gestures, processes frames via high-performance pipelines, and translates them into localized Urdu text and audio output.  
- **Architecture:** Flutter Front-end $\leftrightarrow$ Fast API Backend.  
- **Core Technology:** Built using **TensorFlow** & **MediaPipe** with customized **LSTM (Long Short-Term Memory)** sequence models for high-accuracy video pattern analysis.

### 📚 Smart Library Portal
> **Comprehensive Library and Resource Management System**  
> A full-featured web-based portal developed to digitize book inventories, student logs, and issuance management using secure databases.  
- **Tech Stack:** PHP, Laravel, JavaScript, MySQL, Bootstrap.
